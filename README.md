# Bug Invaders

משחק יריות קצר שבו מגינים על ליבת המערכת מפני נחיל באגים בשלושה שלבים. בחרו חבר צוות עם יכולת מיוחדת, השמידו באגים, אספו תיקוני קוד ושמרו על מד ה־CORE עד לניצחון על מלכת הבאגים.

## משחק במקלדת

- `A` / `D` או חיצי שמאלה / ימינה — הזזת הדמות.
- `רווח` — ירי.
- חץ למעלה — הפעלת היכולת של חבר הצוות הנבחר, כאשר מד ה־ABILITY מלא.
- לחצו על אחד מחברי הצוות בראש המסך כדי לבחור את היכולת שלו.

## משחק במגע

- גררו באזור התחתון של המסך כדי להזיז את הדמות.
- הקישו באזור התחתון כדי לירות.
- החליקו מעלה כדי להפעיל יכולת כאשר מד ה־ABILITY מלא.
- הקישו על חבר צוות בראש המסך כדי לבחור אותו.
